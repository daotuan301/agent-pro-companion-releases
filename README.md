# Agent Pro Companion — releases

Installers and signed update manifests for **Agent Pro Companion**, the Windows program that runs approved browser flows for Agent Pro on an employee's own PC.

- Download the latest installer: **Releases → Latest → `AgentProCompanionSetup-<version>.exe`**.
- The installer is not code-signed yet. Windows may show "Windows protected your PC": click **More info → Run anyway**.
- Updates are offered by the program itself and installed only after you agree. Each update is checked against a signed `manifest.json` / `manifest.sig`.

This repository holds binaries only; there is no source code here.

Bản tiếng Việt: tải bộ cài ở mục **Releases**. Nếu Windows cảnh báo, bấm **Thông tin thêm → Vẫn chạy**.
